## ৩. ক্যারেক্টার শিট

### রাফি (প্রোটাগনিস্ট)
- তরুণ বাঙালি পুরুষ, বাদামি স্কিন, কালো ছোট চুল (গোল বাটি-কাট টাইপ, সামনে হালকা ঢেউ), মোটা ভ্রু, বড় গোল চোখ (সাদা স্ক্লেরা + গাঢ় বাদামি মণি + হাইলাইট)।
- পোশাক: হালকা নীল ফুল-হাতা শার্ট, বুক পকেট, সাদা বোতাম।
- **এক্সপ্রেশন সেট:** নিউট্রাল/চিন্তিত (সোজা ঠোঁট), দুঃখী (নিচে বাঁকা ঠোঁট, ভ্রু উঠানো), আত্মবিশ্বাসী হাসি (একপাশে স্মার্ক), কথা বলা (গোল "O" মুখ ↔ বন্ধ — সিম্পল ২–৩ শেপ লিপ-সিঙ্ক), চোখের পলক, পাশে তাকানো (মণি সরে যায়)।
- **শট টাইপ:** এক্সট্রিম ক্লোজ-আপ (মুখ পুরো ফ্রেম), মিডিয়াম ক্লোজ-আপ (কাঁধ পর্যন্ত), মিডিয়াম (কোমর পর্যন্ত, ক্রিম BG তে ভাসমান), সাইড প্রোফাইল (ইন্টারভিউ রুমে), ওভার-দ্য-শোল্ডার (HR এর ঘাড়ের ওপর দিয়ে), CTA তে সাদা স্টিকার-আউটলাইনসহ।

### এইচআর (প্রতিপক্ষ)
- মধ্যবয়সী পুরুষ, কানের পাশে ধূসর চুল, চিকন কালো চশমা, গোঁফ।
- নেভি স্যুট, সাদা শার্ট, মেরুন টাই, বুকে সোনালি নেমপ্লেট/পকেট।
- এক্সপ্রেশন: আত্মবিশ্বাসী → অস্বস্তি (চোখ সরানো, **কপালে ঘামের ফোঁটা**), মুখ বাঁকানো।
- লোকেশন: বুকশেলফ (ব্লার করা, রঙিন বই) + দেয়ালে ফ্রেমে সার্টিফিকেট, সামনে কাঠের ডেস্ক।

### সেকেন্ডারি এলিমেন্ট
- ব্লার করা ইন্টারভিউয়ারের মাথা/কাঁধ (ফোরগ্রাউন্ড, ডেপথ অফ ফিল্ড)।
- কলম ধরা হাত (নেভি স্লিভ) — লেটারে কাটাকাটি/লেখা।

## ৪. লোকেশন / ব্যাকগ্রাউন্ড লাইব্রেরি
| কোড | বর্ণনা |
|---|---|
| BG-GREEN | গাঢ় সবুজ রেডিয়াল গ্রেডিয়েন্ট + ডায়াগোনাল লাইট-রে + গ্রেইন। হুক/ড্রামাটিক মুহূর্ত, বইয়ের কভার |
| BG-ROOM | ইন্টারভিউ রুম ওয়াইড: ক্রিম দেয়াল, ফ্রেমে ল্যান্ডস্কেপ ছবি (সূর্য+সবুজ পাহাড়), সবুজ রিমের দেয়ালঘড়ি, মাঝে কাঠের টেবিল, গাছের টব, পানির গ্লাস, দুইপাশে দুইজন প্রোফাইলে |
| BG-DESK | উপর থেকে কাঠের ডেস্ক + হলুদ ফোল্ডার + সামান্য বাঁকানো অফার লেটার (কোম্পানি "সবুজবাতি লিমিটেড", পদবি, মাসিক বেতন) |
| BG-OFFICE | HR এর পেছনে ব্লার বুকশেলফ ও সার্টিফিকেট |
| BG-WINDOW | রাফির পেছনে জানালা/পর্দা, পাশে পাতাবাহার গাছ (HR এর দৃষ্টিকোণ) |
| BG-CREAM | প্লেইন ক্রিম পেপার + কোণায় ভিনিয়েট — ইনফোগ্রাফিক, কার্ড, কোট, CTA |
| BG-SOFT | ক্রিম, উপরে হালকা জানালার আলো (ক্লোজ-আপ পোর্ট্রেট) |

## ৬. স্টোরি স্ট্রাকচার (টেমপ্লেট)

ভিডিওটা একটা পরিষ্কার ৬-অ্যাক্ট ফর্মুলা মেনে চলে — নতুন স্ক্রিপ্টও এভাবে ম্যাপ করব:

1. **হুক (0–9s):** অদ্ভুত/চমকপ্রদ ফলাফল আগে দেখানো ("৭ সেকেন্ড চুপ → +৮,০০০") + "কীভাবে? বলছি।"
2. **সমস্যা/ব্যাকস্টোরি (9–25s):** চরিত্রের আগের ভুল, ইনফোগ্রাফিক দিয়ে (ক্যালেন্ডার, কার্ড, প্রগ্রেস বার)।
3. **টার্নিং পয়েন্ট (25–30s):** সিদ্ধান্ত/প্রতিজ্ঞা (স্টিকি নোট)।
4. **ক্লাইম্যাক্স (30–66s):** মূল ঘটনা — কাট-ব্যাক-অ্যান্ড-ফোর্থ (সংলাপ ↔ লেটার), সাসপেন্স মন্তাজ, ফলাফল ও হিসাব।
5. **শিক্ষা (66–100s):** বই/নীতি রেফারেন্স → তুলনা ইনফোগ্রাফিক → ৩-পয়েন্ট চেকলিস্ট → কোট।
6. **CTA + এন্ড কার্ড (100–109s):** প্রশ্ন করে কমেন্ট চাওয়া → ব্র্যান্ড কার্ড।

## ৯. নতুন ভিডিও বানানোর পাইপলাইন (আমার কাজের ধাপ)
আপনি দেবেন: **স্ক্রিপ্ট + ভয়েসওভার অডিও** (ঐচ্ছিক: ক্যারেক্টার/চ্যানেলের নাম, BG মিউজিক)।

1. **টাইমিং:** VO থেকে শব্দভিত্তিক টাইমস্ট্যাম্প (Whisper দিয়ে ফোর্সড অ্যালাইনমেন্ট) → প্রতিটি সাবটাইটেল লাইনের শুরু/শেষ।
2. **শট লিস্ট:** স্ক্রিপ্টকে ওপরের ৬-অ্যাক্ট ফর্মুলায় ভাগ করে প্রতি লাইনে একটা ভিজুয়াল বিট (ক্যারেক্টার শট / ইনসার্ট / ইনফোগ্রাফিক) বেছে নেওয়া।
3. **অ্যাসেট:** SVG ভেক্টরে ক্যারেক্টার (এক্সপ্রেশন ও মুখ শেপসহ), ব্যাকগ্রাউন্ড ও প্রপস — এই গাইডের প্যালেট ও স্টাইলে।
4. **অ্যানিমেশন:** HTML/SVG + কোড-ভিত্তিক টাইমলাইন (সেকশন ৭ এর প্রিসেট), ফ্রেম-বাই-ফ্রেম রেন্ডার (Playwright) → ffmpeg দিয়ে 720×1280 বা 1080×1920 @30fps MP4।
5. **অডিও মিক্স:** VO (−16 থেকে −14 LUFS) + মিউজিক (VO এর নিচে ~−20 dB ডাকিং) + ছোট SFX (পপ, কলমের ঘষা, স্ট্যাম্প, ঘড়ির টিক)।
6. রিভিউ ফ্রেম দেখিয়ে ফিডব্যাক → ফাইনাল এক্সপোর্ট।
